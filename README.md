# Cybersecurity Projects

Four beginner-to-intermediate cybersecurity projects covering networking,
secure coding, web app security, and network monitoring.

| # | Project | Focus Area |
|---|---------|-----------|
| 01 | Port Scanner | Networking fundamentals |
| 02 | Password Strength Checker | Secure coding practices |
| 03 | SQL Injection Scanner | Web application security |
| 04 | Intrusion Detection System | Network monitoring/defense |

## Setup
```
pip install -r requirements.txt
```

Each project folder has its own README with specific instructions.

## ⚠️ Legal Note
All tools here are for educational use on systems/networks you own
or have explicit permission to test. Do not use against systems you
don't control.
